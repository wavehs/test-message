# 🚀 Инструкция по настройке и запуску сервера

Данный сервер является relay-хабом для передачи WebSocket-сообщений между Mac (отправитель) и Windows (получатель).

---

## Вариант 1. Развёртывание в облаке на Render.com (через интернет)

Используется для связи компьютеров через интернет из любой точки мира. Бесплатный тариф Render идеально подходит для этого проекта.

### Шаг 1. Создать Git-репозиторий и загрузить код на GitHub

В терминале на Mac выполните:

```bash
cd /Users/rodion/Develop/test-message

# 1. Инициализируем git-репозиторий
git init
git add .
git commit -m "Initial commit: message relay system"

# Репозиторий уже создан и код отправлен:
# https://github.com/wavehs/test-message
```

---

### Шаг 2. Создать Web Service на Render

1. Перейдите на сайт [render.com](https://render.com) и войдите (удобнее всего через аккаунт GitHub).
2. В панели управления нажмите **New +** → выберите **Web Service**.
3. Найдите в списке и подключите ваш репозиторий `test-message` (**Connect**).
4. Заполните параметры конфигурации:
   - **Name**: `test-message-relay` (или любое другое имя)
   - **Root Directory**: `server` *(⚠️ обязательно укажите `server`, так как код сервера находится в этой подпапке)*
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - **Instance Type**: `Free`
5. Нажмите внизу кнопку **Deploy Web Service**.

---

### Шаг 3. Проверить работу сервера

1. Дождитесь завершения сборки (статус сменится на **Live**).
2. Вверху страницы скопируйте предоставленный URL сервиса, например:
   ```
   https://test-message-relay.onrender.com
   ```
3. Откройте эту ссылку в браузере. Вы должны увидеть JSON-ответ:
   ```json
   {
     "status": "ok",
     "receivers_online": 0,
     "timestamp": "..."
   }
   ```

> [!NOTE]
> На бесплатном тарифе Render сервис переходит в спящий режим после 15 минут неактивности. При первом новом запросе пробуждение занимает около 30–50 секунд.

---

### Шаг 4. Подключение клиентов к серверу в облаке

После получения URL (`https://your-app.onrender.com`), используйте протокол `wss://`:

#### 🍎 Отправитель на macOS:
```bash
cd /Users/rodion/Develop/test-message/sender
pip install -r requirements.txt

# Указываем адрес облачного сервера
export RELAY_SERVER_URL="wss://your-app.onrender.com/ws/send"

# Запускаем отправку сообщений
python send.py
```

#### 🪟 Получатель на Windows:
```powershell
cd receiver

# 1. Установка библиотек (выполняется один раз):
# Либо запустите install.bat двойным кликом, либо в командной строке:
pip install -r requirements.txt

# 2. Запуск (БЕЗ консоли):
# Просто дважды кликните по run.vbs (консоль вообще не появится!)
# Также можно запустить через receive.pyw или run.bat
```

> [!TIP]
> **Как работает получатель:**
> 1. **Консоль вообще не открывается** — при запуске через `run.vbs` (или `receive.pyw`) окно командной строки не появляется.
> 2. Открывается стильное **мини-приложение** с двумя вкладками:
>    - **⚡ Основное**:
>      - Настройка экстренной кнопки (Panic Button) нажатием «Изменить» и любой клавиши/сочетания (по умолчанию `F12`);
>      - Ползунок прозрачности текста (от 0% до 90%);
>      - Чекбокс автоматического сворачивания в трей при запуске (через 5 секунд).
>    - **🎨 Вид текста**:
>      - **Расположение на экране**: Снизу справа, Снизу слева, Сверху справа, Сверху слева, Снизу по центру, Сверху по центру, По центру;
>      - **Шрифт**: Segoe UI, Arial, Calibri, Consolas, Verdana, Tahoma, Georgia, Comic Sans MS, Impact;
>      - **Размер шрифта**: от 10 до 36 px;
>      - **Цвет текста**: палитра быстрых неоновых/контрастных цветов + выбор любого оттенка через пипетку;
>      - Живое превью стиля и кнопка **«Тест на экране»**.
> 3. При нажатии **«Свернуть в трей»** (или автоматически по таймеру) мини-приложение сворачивается в область уведомлений (System Tray возле часов).
> 4. Двойной клик по иконке в трее снова открывает окно настроек. При нажатии на крестик `X` программа не закрывается, а сворачивается в трей. Для выхода выберите «Выход» в меню трея.

## Вариант 2. Локальный запуск на Mac (для быстрой проверки)

Если вы хотите запустить и протестировать всё прямо сейчас без регистрации на Render:

### 1. Запуск сервера:
```bash
cd /Users/rodion/Develop/test-message/server
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
Проверка в браузере: [http://localhost:8000](http://localhost:8000)

### 2. Подключение отправителя (Mac):
В отдельном окне терминала:
```bash
cd /Users/rodion/Develop/test-message/sender
RELAY_SERVER_URL="ws://localhost:8000/ws/send" python send.py
```

### 3. Подключение получателя:
- **Если на том же Mac (тест окна):**
  ```bash
  cd /Users/rodion/Develop/test-message/receiver
  RELAY_SERVER_URL="ws://localhost:8000/ws/receive" python receive.py
  ```
- **Если на компьютере Windows в той же локальной Wi-Fi сети:**
  Узнайте локальный IP-адрес Mac (команда `ipconfig getifaddr en0` на Mac) и укажите его на Windows:
  ```powershell
  set RELAY_SERVER_URL=ws://192.168.x.x:8000/ws/receive
  python receive.py
  ```
